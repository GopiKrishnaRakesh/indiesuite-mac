#  IndieSuite Mac — 80 Native macOS Power Utilities

> **80 hyper-fast, lightweight, zero-bloat native macOS applications designed for developers, creators, focus, routines, desktop pets, and power users.** Built with Swift 6 & SwiftUI, with zero Electron memory overhead and direct website/Homebrew distribution.

---

## 📦 What's Inside (80 Native Standalone Apps)

### 🐾 1. Interactive Desktop Pets & Gamified Habits (Apps 31–35)
- **`31-petpals-desktop`**: Interactive desktop pet that walks on windows, sleeps during focus sessions, and nudges hydration.
- **`32-bonsaigrow`**: Virtual Zen Bonsai tree that grows lush leaves with completed focus sessions and withers if distracted.
- **`33-deskfish-aquarium`**: Translucent mini-aquarium HUD with fish whose health depends on habit streaks.
- **`34-pomodorodragon`**: RPG Pomodoro egg that hatches into unique dragons as you complete 25m focus cycles.

## 🚀 Quick Start

### Compile All 80 Apps
```bash
./scripts/build_all.sh
```

### Run Any App
```bash
cd "apps/31-petpals-desktop" && swift run
```

### Generate All 80 Homebrew Casks
```bash
./scripts/generate_cask.sh
```

### Preview Storefront Web App
```bash
npx http-server website -p 4242
```
Open [http://localhost:4242](http://localhost:4242)
