Engineered for Power

Built-in tools that make Finder obsolete.

Accurate folder weights & Group By sorting.

Never guess which folder is taking up all your storage. Pathway computes sizes asynchronously in a Swift 6 actor without freezing your UI.

  • ✓ Sort by true byte weight: Folders sort by actual size rather than empty defaults.
  • ✓ Ascending & Descending controls: Explicit toggles in header, toolbar, and menu.
  • ✓ Group By categories: Group items into sections by Type/Kind, Date Modified, Size brackets, or Color Tags.

Batch image & document conversions right inside context menu.

Stop opening third-party websites or paid utilities just to convert photos or combine files. Pathway uses native macOS graphics frameworks:

  • ✓ Images: Convert instantly to JPEG, PNG, HEIC, TIFF, GIF, or merge multiple into a multi-page PDF.
  • ✓ Documents: Transcode files into PDF, Word (.docx), Rich Text (.rtf), Plain Text, or HTML.
  • ✓ Archives: 1-Click ZIP and TAR compression, plus in-place extraction.
